Second Brain

A local-first workspace for exploring research papers, asking source-grounded questions, and building an editable manuscript draft with your own Ollama models.

Quick start Workflow Models Limitations Privacy
01

Run it locally

Install Python 3.12 and Ollama. In PowerShell, open the PDF READER folder and run:

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py

Open http://localhost:8501. The app uses http://localhost:11434 for Ollama by default.

02

Build your library

Open Library and import the local Referensi/ folder or select individual PDF, DOCX, XLSX, PPTX, image, TXT, and CSV files. Sources and extracted passages are indexed in local SQLite.

Search paper text, titles, and author keywords. Filter by publication year and affiliation country. Review publication trends, themes, country counts, and the affiliation map. Correct detected metadata in the editable table.

Affiliation location is not experiment location. Map pins use country centroids from detected author affiliations. Verify detected countries before analysis.
03

Ask and draft

  • Home: ask a question across the local library; answers include source file and page labels.
  • Ask library: explore evidence across indexed papers and inspect the cited passages.
  • Page builder: choose a section, add your research question and notes, then draft from relevant sources.
  • Use Apply changes to save edited text and update the page preview. Use Paraphrase with Qwen or ask Qwen about the active section. Drafts autosave locally.
  • Export the manuscript to DOCX when you need a portable copy.

Qwen paraphrasing should preserve citations, but compare generated wording with the cited source before use.

04

Choose local models

Set model names in the sidebar to match ollama list. Example downloads:

ollama pull qwen3:8b
ollama pull qwen3-vl:8b
ollama pull nomic-embed-text
  • qwen3:8b handles Q&A and writing.
  • qwen3-vl:8b analyzes images and selected scanned PDF pages.
  • nomic-embed-text enables semantic search. Without it, retrieval falls back to keyword search.

Bulk PDF import is text-first. To analyze scans, enable the Qwen-VL option; automatic visual analysis is limited to the first two pages of each PDF.

05

Limitations to know

  • Title, year, keywords, and country are heuristically extracted from the first page. Verify and correct them before relying on bibliometric summaries.
  • Country counts are not a full co-authorship or collaboration-network analysis.
  • Spreadsheet and presentation charts are indexed from underlying series data; visual styling and annotations may be lost.
  • Citations identify source file and page/sheet/slide, but do not yet produce a full APA/IEEE bibliography or DOI metadata.
  • The preview is not a fully paginated WYSIWYG Word editor.
  • Models can produce incorrect claims. Researchers must verify evidence, methods, results, citations, and novelty.
06

Privacy and local data

Imported papers, extracted text, metadata, indexes, and drafts are stored under data/. Model requests go to the configured Ollama address. Use a local address if documents must not leave this computer.

The affiliation map loads basemap tiles from Carto; paper text is not sent to Carto, but the provider receives tile requests. The data/ and Referensi/ folders are excluded by .gitignore.

Run tests with python -m unittest discover -s tests -v.

Second Brain is a research-writing prototype. Review every claim and citation before publication.
